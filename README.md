# モノシリ（iPad / Swift Playground 版）

## iPadで開く
1. App Store から **Swift Playground** を入れる
2. この zip をファイルアプリで展開し、`MonoSiri.swiftpm` をタップ（または Swift Playground の「開く」から選ぶ）
3. 右上の ▶︎ で実行 →「位置情報と通知を許可する」

Mac でも同じ `MonoSiri.swiftpm` を Xcode か Swift Playground で開ける。

## 試し方
- 「近く」タブ右上の ✈︎（ワープ）で、大阪城・奈良公園・大仙陵古墳などに移動したことにできる。
  iPad は移動のシミュレーションができないので、記事の選び方の調整はこれで行う
- 「現在地に戻る」で実際の位置に戻る
- 復習の出題は覚えてから20時間後。すぐ試すときは `Models.swift` の `ReviewScheduler.firstDelay` を `60` にして、
  カードにする → 別の場所へワープ → 1分後に元の場所へワープ →「復習」タブ、の順で確認できる

## Mac版（XcodeGen）との違い
- ファイルはすべてフォルダ直下（Swift Playground はサブフォルダの扱いが不安定なため）
- 位置情報の権限は「使用中のみ」だけ設定している。**アプリを閉じているときの復習通知**には「常に許可」が必要で、
  App 設定 › 機能 に「位置情報（常に）」があれば追加する。なければ、復習はアプリを開いたときの「ここで覚えたカード」表示で行う
- アイコンと色は App 設定から好きに選べる
